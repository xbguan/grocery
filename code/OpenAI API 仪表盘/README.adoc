= OpenAI 仪表盘 — macOS 菜单栏 API 用量与 ChatGPT 订阅
:sectnums:
:toc: left
:toclevels: 2

一个原生 SwiftUI 菜单栏小工具，随时查看 OpenAI *API 平台* 组织级的花费、token 用量与额度。

它服务的是 API 平台（platform.openai.com）的管理员视角，与 ChatGPT 订阅是两套体系，详见下文。

== 已安装

* 应用位置：`/Applications/OpenAI 仪表盘.app`（放 `~/Applications/` 同样能用，卸载脚本两处都会找）
* 源码工程：`/Users/xbguan/project/grocery/code/OpenAI API 仪表盘/`
* 配置目录：`~/Library/Application Support/OpenAIApiDashboard/`
* Bundle ID：`com.xbguan.openai-api-dashboard`
* 安装包：`dist/OpenAI 仪表盘-1.10.1.dmg`（Intel / Apple 芯片通用）

== 首次使用（必须做一次）

. 点击菜单栏图标 → 左下角「设置」→「API 用量」
. 填入 *Admin API Key*（`sk-admin-` 开头），点「测试连接」确认
. 点「保存」→ Key 在本机加密保存，面板自动刷新

获取 Admin Key：https://platform.openai.com/settings/organization/api-keys[platform.openai.com → Organization → Admin keys]
普通项目 Key（`sk-proj-`）读不到组织用量，会报 403。

可选：填 *项目 ID*（`proj_...`）只统计单个项目；填 *菜单栏备注名* 便于区分多个账号。

=== 视觉与交互

界面按 *Liquid Glass* 材质重做（macOS 26 / iOS 26 起的系统语言）：底色渐变面 + 半透明玻璃卡片（顶部高光描边、底部收紧、柔影分层），不再用分隔线切块。浅色与深色两套 token 都单独调过对比度。

窗口行为：

* 系统菜单栏只显示仪表盘图标。API 用量、ChatGPT 订阅与设置在同一个固定大小的面板右侧切换。
* 左侧顶部刷新按钮更新全部已连接的数据源。API 配置保存后返回用量页。
* 在设置的「ChatGPT 订阅」组点「连接本机 Codex」，读取已登录账号的套餐、Codex 七天额度、周重置时间及剩余重置机会。此功能需要本机安装 Codex 并使用 ChatGPT 账号登录，使用文件凭据模式。订阅到期日未由此数据源提供。断开连接会清除面板中的读数。

== 图标设计

App 图标由代码绘制（`Sources/OpenAIBar/Logo.swift`），构建时自动生成 `AppIcon.icns`，不需要手工准备素材：

* *深色圆角方块*：自上而下的冷灰渐变 + 顶部柔光，接近 OpenAI 视觉体系的中性冷调
* *白色表盘弧*：直接对应「仪表盘」这件事
* *三根递增柱*：用量与花费；只有最高的一根用品牌绿，其余灰阶——保持那种「几乎全黑白、只留一处色彩」的克制

菜单栏图标：*开口圆环 + 指针 + 中心轴点*，18pt 下也能读出「表盘」。早期版本用过三根柱子，在菜单栏尺寸下被读成手机信号格，故弃用。指针不随金额转动 —— 它只是标志，不是读数。

三种状态共用同一套几何，只改指针，不换图形（换形状会让图标在菜单栏上"跳"，早先那版为此显示成警告三角，已废弃）：

* *正常*：指针指向右上 55°
* *未配置 Key*：不画指针，只剩环与轴点，读作"静止待机"
* *出错*（Key 无效 / 断网）：指针压到底部 270°，读作"指针掉底了"

== 数据来源与限制

花费、用量：`GET /v1/organization/costs` 与 `GET /v1/organization/usage/completions`，官方接口，按 *UTC 自然日* 统计（与 OpenAI 后台一致）。

=== 只针对 API 平台，与 ChatGPT 订阅无关

本 App 只读取 *API 平台（platform.openai.com）组织级* 的数据：按 token 计费的用量与成本，需要 Admin Key。

API 计费与 ChatGPT 订阅分别管理；符合条件的订阅可领取关联到 API 组织的赠送额度。App 里的「API 余额」以该组织账单数据为准，可能包含订阅赠送额度或预充值额度。

余额：*任何 API Key 都读不到余额*，这不是权限问题而是接口限制。实测（2026-10）用 Admin Key 请求：

[source]
----
GET /v1/dashboard/billing/credit_grants  → 403
{"error":"Your request ... must be made with a session key
 (that is, it can only be made from the browser).
 You made it with the following key type: secret."}
----

换任何 key 类型都不行，`/v1/organization/*` 下也没有余额端点（`/credits`、`/organization/credits` 等全部 404）。所以余额只有两条路：

* *实时余额（推荐，需你登录一次）*：设置的「API 用量」组里打开「显示实时余额」，App 用一个隐藏的 WKWebView 打开平台账单页，页面自己会请求 `credit_grants`，我们在 `documentStart` 注入钩子把**响应体**截下来，解析 `total_available` 与逐笔 grant 明细；概览没有效期时再加载同一登录态下的 Credit grants 页面。取得明细后显示最近一笔尚未用完额度的到期倒计时与时间，否则显示「效期未取得」。登录态存在 App 自己的 WebKit 容器（`~/Library/WebKit/com.xbguan.openai-api-dashboard`），不保存密码、不保存 cookie 明文、不外发。
* *估算兜底*：未开启实时余额、或实时读取失败时，退回 `subscription`（额度上限）− `usage`（已用）的推算值，界面标注「估算」。

⚠️ 实现上有一条硬约束：*不能自己发这个请求*。从页面上下文 fetch `api.openai.com` 会被 CORS 挡掉（实测 `Load failed`），只能让页面发、我们截。

若你看到「估算」，说明实时余额没读到（未登录 / 登录过期 / 页面改版），点卡片上的「登录」或设置里的「重新登录」即可。

== 刷新

菜单栏默认每 5 分钟自动刷新（设置的「通用」组可选 5、15、30 或 60 分钟），点左栏顶部 `↻` 可手动刷新。

== 安装到另一台 Mac（DMG）

image::dmg-window.png[width=520]

`dist/OpenAI 仪表盘-1.10.1.dmg` 是标准拖拽式安装镜像：打开后把左边的 App 拖进右边的「应用程序」即可。

* *通用二进制*：同时包含 `arm64` 与 `x86_64`，Intel 与 Apple 芯片的 Mac 都原生运行，不需要 Rosetta
* *系统要求*：macOS 14.0 及以上

=== 首次打开被拦怎么办

本 App 是 *ad-hoc 签名*——没有 Apple 开发者证书，无法做公证。通过 AirDrop、邮件、浏览器等方式传过去的 DMG 会带上"来自互联网"的隔离标记，首次打开时 macOS 会拦下：

[quote]
____
"OpenAI 仪表盘"无法打开，因为无法验证开发者。
____

两种放行办法，任选其一：

. *右键 → 打开*：在「应用程序」里右键点 App 图标 → 「打开」，弹窗里再点一次「打开」。只需一次，之后正常双击。
. *命令行*（反复遇到时更省事）：
+
[source,bash]
----
xattr -cr "/Applications/OpenAI 仪表盘.app"
----

用 U 盘拷贝一般不带隔离标记，双击即可。若提示的是「App 已损坏，无法打开」，同样是隔离标记作祟，用第 2 条处理。

=== 换机器后要重新填 Key

Admin Key 存在 *该用户的 Application Support 目录* 里，不随安装包走。新机器首次启动会回到"未配置"状态，点「填入 Admin Key」重新填一次即可。两台机器可以各填各的，互不影响。

== 连不上怎么办

面板提示「连不上 api.openai.com」时，先看代理：国内直连这个域名基本不通，需要 Clash / VPN 在跑。代理恢复后点面板里的「重试」即可，不用重启 App。

== 构建

[source,bash]
----
cd "/Users/xbguan/project/grocery/code/OpenAI API 仪表盘"

./build.sh                 # 只编译本机架构（日常开发，增量几秒）
./build.sh --universal     # Intel + Apple 芯片通用版本
./build.sh --install       # 编译通用版并安装到 /Applications

./make-dmg.sh              # 用现有产物打 DMG
./make-dmg.sh --rebuild    # 先编译通用版再打 DMG（发布用）
----

产物：

* `.build/bundle/OpenAI 仪表盘.app` —— 可运行的原件（不再往项目根拷 .app，见下文）
* `dist/OpenAI 仪表盘-<版本>.dmg` —— 分发包

=== 项目规约

发布相关的两条硬性约定，写在 `AGENTS.md`：

. *每次改动都要出新版本 DMG*：先改 `Resources/Info.plist` 的版本号（修 bug 末位 +1，新功能次位 +1，`CFBundleVersion` 每次 +1），再 `./make-dmg.sh --rebuild`，产物留 `dist/`，且 `dist/` 只保留最新版本的一个 DMG（旧的删掉）
. *必须同时支持 Intel 与 M 芯片*：DMG 内 App 必须是 `x86_64 + arm64` 通用二进制，不依赖 Rosetta；两个架构由 `--triple` 分别交叉编译后 `lipo` 合并，打包后要核对 `lipo -archs`

注：本机只有 Command Line Tools、没有完整 Xcode，因此有几处绕行：

* 构建走 `swift build --disable-sandbox`（宿主环境不允许 sandbox-exec，否则 manifest 编译阶段就报 `Operation not permitted`）
* *通用二进制不能用 `--arch a --arch b`*：那条路径依赖 xcbuild，CLT 下不存在。`build.sh` 改为用 `--triple` 分别交叉编译两个架构，再 `lipo -create` 合并
* DMG 的窗口布局（尺寸、背景图、图标位置）*不走 AppleScript 调 Finder*：本机 osascript 一律返回 `-10004`（自动化权限未授予），`create-dmg` 之类的工具同样依赖 AppleScript 因此不可用。改为直接写 `.DS_Store`（`Tools/dmg-layout.py`，依赖已内嵌在 `Tools/pylib`，不需要 pip 安装任何东西）
* *不往项目根拷 `.app`*：该路径被宿主安全策略保护，写入一律 `Operation not permitted`。构建产物留在 `.build/bundle/`，安装用 `--install`
* *拷 App 进 DMG 用 `cp -R` 而非 `ditto`*：ditto 走"写临时文件再 rename"，会被同一条策略拦掉（报 `.BC.T_xxx` 删除失败）

首次全量编译约 2 分钟，之后增量几秒；通用版本要把两个架构各编一遍。

== 安全说明

1.7.0 起，首次在设置中填写一次 Admin Key，此后覆盖安装会继续使用原来的凭据和外观等设置。App 不会读取旧版钥匙串。

凭据位于 `~/Library/Application Support/OpenAIApiDashboard/Credentials/`。App 以 AES-256-GCM 加密 Key，将带格式版本的密文写入 `admin.enc`；首次保存生成的随机密钥存入 `local.key`。目录权限为 700，两个文件为 600。取得这两个文件的同用户程序可能解密，请勿分享该目录。普通设置存于同级的 `config.json`。

== 卸载

1.10.1 起应用更名为「OpenAI 仪表盘」。从旧名升级时，先退出旧 App，在「应用程序」中将「OpenAI API 仪表盘.app」重命名为「OpenAI 仪表盘.app」，再从镜像拖入并选择替换。配置、凭据及平台会话沿用原位置。此后的覆盖升级直接替换 App。完整卸载会清除设置、加密凭据和平台登录态。

=== 手动清理

[source,bash]
----
# 1. 删 App
mv "/Applications/OpenAI 仪表盘.app" ~/.Trash/

# 2. 仅曾安装 1.6.1 或更早版本时，按需清理遗留凭据
security delete-generic-password -s "com.xbguan.openai-api-dashboard" -a "openai-admin-key-v3"
# 曾安装旧版本时，按需再删除旧条目
security delete-generic-password -s "com.xbguan.openai-api-dashboard" -a "openai-admin-key-v2"
security delete-generic-password -s "com.xbguan.openai-api-dashboard" -a "openai-admin-key"

# 3. 删配置
rm -rf ~/Library/"Application Support"/OpenAIApiDashboard
----

也可以在「钥匙串访问」里搜索 `openai-api-dashboard`，右键删除那条「OpenAI API 仪表盘 Admin Key」。

=== 只想换 Key、不卸载

设置中点 Admin Key 旁的「清除」即可——删除当前版本的加密凭据，App 和其他设置都保留。旧版凭据可按上面的手动命令或卸载脚本清理。
